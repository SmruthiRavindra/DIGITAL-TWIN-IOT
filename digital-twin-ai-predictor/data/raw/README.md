# Raw Data

Place original NASA CMAPSS Turbofan Engine Degradation dataset files here:

- `train_FD001.txt`
- `test_FD001.txt`
- `RUL_FD001.txt`

## Download

Get the dataset from:
- [NASA Prognostics Data Repository](https://www.nasa.gov/content/prognostics-center-of-excellence-data-set-repository)
- [Kaggle: CMAPSS Jet Engine](https://www.kaggle.com/datasets/behrad3d/nasa-cmaps)

> ⚠️ Do NOT push these files to GitHub. They are excluded via `.gitignore`.
